## Overview

**LEXI** is the voice-activated holographic AI core and studio command interface for **LexiTech Legal & Tax AI Studio**. Engineered with a real-time audio-reactive neural core, Web Speech recognition, neural speech synthesis, and optional Gemini API integration, LEXI lets users speak naturally to query studio capabilities or launch any of LexiTech's four grounded forensic AI engines via voice command.

---

## Core Capabilities

- **Holographic Audio-Reactive Core:** Multi-ring cyber-forensic visual interface that shifts dynamically between standby, passive wake-word listening, active voice capture, and live vocal transmission.
- **Hands-Free Wake Word & Voice Control:** Built-in browser speech recognition supporting push-to-talk and passive `"Hey Lexi"` wake-word detection alongside spoken neural responses.
- **Autonomous Studio Module Routing:** Voice and text command parsing that launches LexiTech's four live production apps on demand:
  - **Module 01:** [Legal & Tax Document AI Assistant](https://streamlit.app)
  - **Module 02:** [Tax-Trap Contract Scanner](https://streamlit.app)
  - **Module 03:** [Worst-Case Life Event Simulator](https://streamlit.app)
  - **Module 04:** [LexiTech Pro Cloud Workspace](https://streamlit.app)
- **Zero-Exposure Client-Side Key Vault:** Optional Gemini API integration stored strictly in the user's local browser (`localStorage`)—never committed to source control or exposed on public servers.

---

## Technical Architecture

- **Frontend & Visual Core:** Single-file HTML5, CSS3 holographic animations, `Plus Jakarta Sans` + `JetBrains Mono` typography
- **Voice & Audio Pipeline:** Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition` & `speechSynthesis`)
- **Cognitive Backend:** Google Gemini API (`gemini-2.5-flash`) with offline studio-command fallback
- **Hosting:** GitHub Pages
